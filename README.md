# 作文小學堂

給孩子的作文練習 App（PWA）。從幼兒「點圖拼句」，到一句話日記、看圖寫短文，再到國小中高年級與國中的記敘、寫景、論說、抒情。

- 每一課固定流程：👀 看範文 → 💡 學一學 → ✍️ 寫一寫 → 🎤 讀一讀
- 範文、技巧、自己寫的作文，都能邊念邊掃字（卡拉 OK），可暫停、再接著念；朗讀不念標點
- 只鼓勵、不扣分：自己打勾檢查，存到「我的作品」
- 作品與草稿只存在這台裝置的瀏覽器裡，不上傳

課程資料在 `data.js`、`data2.js`。`tpl.html` 是樣板（版面與程式），`index.html` 由它組出來。

- 作文用稿紙格式呈現：直式、由右到左、一格一字、標點占一格、每段開頭空兩格、題目置中在第一行；標點不在行首、前引號不在行尾
- 「🔍 幫我檢查」找常見錯字（含簡體字）和標點問題，用對照表找，不是萬能的
- 課程資料：`data.js`、`data2.js`、`data3.js`；檢查規則：`check.js`
